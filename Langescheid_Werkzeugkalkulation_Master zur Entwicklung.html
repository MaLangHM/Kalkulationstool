Hilfe

✅ Arbeitsreihenfolge (empfohlen)

  1. „Projekt“: Projektname/Nummer setzen (optional), dann speichern.
  2. „Material“: Materialzeilen erfassen, Summen prüfen (oben), Faktor prüfen.
  3. „Produktionsplanung“: Arbeitsschritte erfassen, Minuten/Zeiten prüfen, Faktor prüfen.
  4. „Fremdfertigung“: Dienstleister (FF2) erfassen, Werkzeugkosten + Mengen/Preise pflegen, Faktor prüfen.
  5. „Dashboard“: Konsolidierte Werte prüfen, Status/Legenden beachten.
  6. „Export“: JSON-Export als Backup erzeugen.

🧱 Modul „Material“

Ziel: Materialkosten konsistent erfassen. Das Dashboard übernimmt die berechneten Summen.
  • Pflicht für sinnvolle Summen: Preis pro Materialstück, zu fertigende Bauteile, Geometrie/Abmessungen (je nach Materialart).
  • Kommawerte sind erlaubt (z. B. „12,34“). Rundung erfolgt beim Verlassen des Feldes.
  • Automatik: leere Endzeile wird automatisch ergänzt (Excel-Verhalten).

🏭 Modul „Produktionsplanung“

Ziel: Bearbeitungszeiten (Minuten) je Schritt erfassen. Das Dashboard konsolidiert die Produktionskosten.
  • Zeilen: Arbeitsschritt + Maschine + Geometrie + Zeitwerte.
  • „Excel-Modus“: schnellere Eingabe per Tastatur; ESC hebt Markierungen auf.
  • Faktor: wird genutzt, um Minuten in Euro umzurechnen (Parametereingabe oben).

🧾 Modul „Fremdfertigung“ (FF2 Card-Ansicht)

Ziel: Angebote je Dienstleister und Stückzahl erfassen. Das Dashboard summiert je Stückzahl.
  1. „Neuer Dienstleister“ → Dienstleister/Tätigkeitsfeld wählen.
  2. „Werkzeugkosten gesamt“ pro Dienstleister einmalig pflegen.
  3. Mengenzeilen: Stückzahl (Stück) und Preis je Stück pflegen.
  4. Faktor prüfen (Minuten → Euro bzw. definierte Umrechnung).
  5. Dashboard prüfen: je Stückzahl wird „inkl. Werkzeug“ ausgewiesen.
Hinweis: Ein Stern „*“ im Dashboard bedeutet „Fallback“ (nächst-kleinere Menge verwendet).

💾 Backup & Wiederherstellung

  • „Export“ erzeugt eine JSON-Datei als Backup („LocalStorage“ kann voll werden).
  • Wenn Speichern fehlschlägt, erscheint eine Warnung. Export ist dann der sichere Weg.

Hilfe – Fremdfertigung
Kurzanleitung + Wizard-Modus
1) In „Dienstleister“ oder „Tätigkeitsfeld“ klicken → Auswahl-Dialog öffnet. Suche eingeben, Treffer auswählen.
2) „Menge“ > 0 eingeben und mit Enter bestätigen → neuer Zeilenblock wird erstellt (Name/„Tätigkeitsfeld“ werden übernommen).
3) Kostenfelder in Zeile 1: „Bearbeitungskosten / Stück [€]“ und „Werkzeugkosten gesamt [€]“.
4) Zeile 2 berechnet automatisch: „Bearbeitungskosten gesamt [€]“, „Gesamtkosten inkl. Werkzeug [€]“, „Werkzeugkosten/Stück [€]“, „Kosten/Stück inkl. Werkzeug [€]“.
5) Empfehlung oben zeigt den aktuell günstigsten Eintrag (nach „Gesamtkosten inkl. Werkzeug [€]“).
6) „PDF“ nutzt den Druckdialog (Browser-Funktion).
